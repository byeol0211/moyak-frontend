## Flutter 사용
AI 채팅 + → 카메라 또는 시스템 앨범 → 최대 2장 미리보기/삭제 → 사진 전송.
같은 약의 앞면과 뒷면 순서. 사진은 JPEG/PNG, 한 장 8MB 이하. 선택 시 1600px/품질90으로 축소 요청.
POST /pills/identify?otc_only=false&limit=3, multipart files 반복, 전체 응답 90초 제한.
실패하면 선택한 사진을 유지하며 재시도 가능. 서버 message/note와 최대 3개 후보를 표시.
후보의 설명 버튼을 누르면 기존 /chat로 약 이름을 질문하고 기존 채팅 history를 유지.
사진 인식 후보는 확정된 약품으로 채팅 history에 자동 삽입하지 않음. 점수를 확률로 표시하지 않음.
서버 키는 앱에 포함하지 않음. 미리보기에서는 실제 사진 분석을 호출하지 않음.
사진은 메모리에서 표시하며 대화/사진 영구 보관 기능은 추가하지 않음.
