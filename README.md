# MOYAK 소비자 앱

스마트 의약품 자판기 서비스의 Flutter 소비자 앱입니다. 키오스크는 별도 프로젝트에서 개발합니다.

## 개발 현황 (2026-10-17)

- 홈·지도·챗봇·약사 상담·마이페이지와 서버 없이 확인하는 화면 미리보기 모드 구현
- 자판기 이름·주소·코드 검색, 상세 재고 조회 및 챗봇 백엔드 API 연동
- 약사 상담 요청·대기·취소, 상담 내역·전자 구매 허가서 조회 연동
- Daily 영상통화 및 통화 화면 위 반투명 채팅 UI 구현, **약사 웹 ↔ 휴대폰 앱 실제 통화 확인 완료**
- QR 스캔 자판기 연결 및 Android APK 빌드·갤럭시 S23 실행 확인 완료
- 앱에서는 재고 조회만 제공하며, 상품 구매·결제는 자판기에서 진행

남은 작업: 통화 중 채팅·종료 동기화 및 연결 복구 검증, 녹음·약사 검토 요약 연동, 카메라 권한 처리와 화면 배치 개선. 로그인·회원가입은 서버 인증 API 준비 후 연결할 예정입니다.

## 실행 방법

백엔드 없이 확인하려면 실행 후 로그인 화면에서 **회원가입 없이 화면 미리보기**를 선택하세요.

```sh
flutter pub get
flutter run
```

실제 서버(Render)와 연결해서 실행하려면 서버 주소를 지정하고 로그인 화면에서 **게스트로 계속하기**를 선택하세요.

```sh
flutter run --dart-define=API_BASE_URL=https://moyak-backend.onrender.com
```
